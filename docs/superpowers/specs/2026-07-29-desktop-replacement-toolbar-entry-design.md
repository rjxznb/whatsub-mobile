# Library 桌面替换入口轻量化设计

## 目标

将 Library 详情页播放器下方的大型“发送到桌面端下载”卡片移除，改成导航栏右上角的轻量图标入口。该功能属于低频辅助功能，不应持续占用字幕阅读空间。

## 界面

- 仅当当前条目仍需使用 YouTube 播放器、并且符合桌面替换条件时，显示右上角 `desktopcomputer` 图标。
- 点击图标后弹出 sheet。sheet 内保留功能说明、桌面在线状态、离线提醒、失败原因，以及“发送到桌面端下载”主按钮。
- 任务处于等待或处理状态时，图标叠加小型进度提示；任务失败时叠加红色感叹号。
- 发送成功后 sheet 保持可查看状态，但发送按钮禁用，并显示真实的 pending/processing 状态。

## 行为与数据

- 复用现有 `LibraryDetailViewModel`、确认对话框、桌面在线检测、时长上限预检和队列状态，不修改 API 或后端。
- 已知视频时长严格超过服务端返回的套餐上限时，仍在客户端阻止请求；等于上限或未知时继续由后端校验。
- 横屏播放器隐藏导航栏，因此该入口只出现在正常竖屏详情页；这符合低频功能定位。

## 验证

- 可替换条目显示图标；OSS 视频或不符合条件的条目不显示。
- 点击图标展示 sheet，sheet 能触发现有确认和发送流程。
- pending、processing、failed 三种状态在图标与 sheet 中正确呈现。
- 原大型卡片完全移除，字幕列表顶部不再被占用。
- 运行现有 `LibraryDesktopReplacementTests`、完整 iOS XCTest 与模拟器构建。
